Bio Book
========

Character bios and private notes for players, opened from chat. Fabric, Minecraft 26.3, needs Fabric API.

Click the head next to a player's chat message to open their bio. Press B or run `/bio` to open your own and edit it.

Needs to be on both the server and the client.

Bios and notes are saved in the world folder under `data/biobook/journals.dat`.
